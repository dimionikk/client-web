Клієнтські технології Web-програмування

Лабораторна робота №1
Тема: Налаштування середовища розробки: VS Code, Live Server, DevTools. Контроль версій та публікація статичного сайту.

Персоналізована веб-сторінка, що демонструє базовий цикл розробки клієнтської частини: локальна розробка → перевірка результату → контроль версій → публікація. Сторінка містить персональні дані, компонент з ідентифікатором сторінки, що генерується скриптом при завантаженні, та збережений в Local Storage.

Опубліковано на GitHub Pages: https://dimionikk.github.io/client-web/
